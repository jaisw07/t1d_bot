The  ollama.log  shows exactly what is happening:

    slot print_timing: id  0 | task 170452 | n_decoded =    524, tg =  28.24 t/s

  Ollama is not frozen. However, instead of returning a tiny 20-token JSON object like  {"topic": "...", "keywords": [...]} , the local model has entered
  a loop and is generating a massive response (524+ tokens and counting).

  At  28 tokens/second , generating 500+ tokens takes over 20 seconds per chunk. For 69 chunks, this single step would take nearly 30 minutes, making it
  extremely slow.

  ### The Solution: Limit generated tokens and set timeouts

  We need to:

  1. Kill the current run.
  2. Add a  timeout=30.0  to the client so it never hangs indefinitely.
  3. Pass  num_predict=150  ( max_tokens ) to the metadata query so the LLM is forced to stop generating after 150 tokens. This will drop the generation
  time back down to under 2 seconds per chunk.

    import os

    def patch_file(filepath, replacements):
        if not os.path.exists(filepath):
            print(f"Error: {filepath} not found.")
            return False
        with open(filepath, 'r', encoding='utf-8') as f:
            content = f.read()
        original = content
        for target, replacement in replacements:
            if target not in content:
                continue
            content = content.replace(target, replacement)
        if content != original:
            with open(filepath, 'w', encoding='utf-8') as f:
                f.write(content)
            print(f"Successfully patched {filepath}")
            return True
        return False

    # 1. Patch client.py
    patch_file("src/llm/client.py", [
        (
            'def chat(self, messages: list[dict], model: str, temperature: float = 0.1) -> str:',
            'def chat(self, messages: list[dict], model: str, temperature: float = 0.1, max_tokens: int = None) -> str:'
        )
    ])

    # 2. Patch ollama.py
    patch_file("src/llm/ollama.py", [
        (
            'self._client = ollama.Client(host=host)',
            'self._client = ollama.Client(host=host, timeout=30.0)'
        ),
        (
            'def chat(self, messages: list[dict], model: str, temperature: float = 0.1) -> str:\n        response = self._client.chat(\n
  model=model,\n            messages=messages,\n            options={"temperature": temperature},\n        )\n        return
  response["message"]["content"]',
            'def chat(self, messages: list[dict], model: str, temperature: float = 0.1, max_tokens: int = None) -> str:\n        options = {"temperature":
  temperature}\n        if max_tokens is not None:\n            options["num_predict"] = max_tokens\n            \n        response = self._client.chat(\n
  model=model,\n            messages=messages,\n            options=options,\n        )\n        return response["message"]["content"]'
        )
    ])

    # 3. Patch gemini.py
    patch_file("src/llm/gemini.py", [
        (
            'def chat(self, messages: list[dict], model: str, temperature: float = 0.1) -> str:',
            'def chat(self, messages: list[dict], model: str, temperature: float = 0.1, max_tokens: int = None) -> str:'
        ),
        (
            'config = types.GenerateContentConfig(\n            system_instruction=system_instruction,\n            temperature=temperature\n        )',
            'config = types.GenerateContentConfig(\n            system_instruction=system_instruction,\n            temperature=temperature,\n
  max_output_tokens=max_tokens\n        )'
        )
    ])

    # 4. Patch metadata_generator.py
    patch_file("src/ingestion/metadata_generator.py", [
        (
            'raw_response = self.llm.chat(messages, model=self.model, temperature=0.1)',
            'raw_response = self.llm.chat(messages, model=self.model, temperature=0.1, max_tokens=150)'
        )
    ])

    print("Patching completed!")
    EOF
