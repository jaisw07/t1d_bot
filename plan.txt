  Evaluation Notebook Plan

  Objective
  Change all local model references to gemma4:e4b in the source code and create a testing notebook that evaluates the
  generator against a specific question bank, saving results systematically.

  Key Files & Context
   - Target Source Code: src/generation/generate.py
   - Question Bank: dataset/testing_questions/voiculescu_et_al.txt
   - New Module: src/testing/evaluate.py
   - New Notebook: run_voiculescu_evaluation.ipynb
   - Output Artifact: tests/voiculescu_et_al/results.json

  Implementation Steps
   1. Update Model Reference:
      - In src/generation/generate.py, modify the default model_name in the MedicalRAGGenerator.__init__ signature from
        "gemma4:e2b" to "gemma4:e4b".

   2. Create Evaluation Logic (src/testing/evaluate.py):
      - Create a load_questions(file_path) function to read dataset/testing_questions/voiculescu_et_al.txt. It will
        parse the "Type: ---" headers and the questions following them into a list of dictionaries: [{"type": "...",
        "question": "..."}].
      - Create a run_evaluation(questions_file, output_dir, generator) function.
      - This function will use tqdm to display a progress bar while iterating over the questions.
      - For each question, it will call generator.generate(question), capturing the answer.
      - It will maintain a list of results and periodically (or at the end) save them to
        tests/voiculescu_et_al/results.json, ensuring each entry contains question, answer, and type.

   3. Create Testing Notebook (run_voiculescu_evaluation.ipynb):
      - Create a new, clean Jupyter notebook.
      - Cell 1: Import MedicalRAGGenerator from src.generation.generate and run_evaluation from src.testing.evaluate.
      - Cell 2: Initialize MedicalRAGGenerator pointing to dataset/master/ISPAD-English-2022/master_corpus.jsonl and
        using gemma4:e4b.
      - Cell 3: Call run_evaluation with the relevant paths to process the dataset and save the JSON output, showing the
        progress bar cleanly within the notebook interface.

  Verification & Testing
   - Ensure the updated gemma4:e4b reference in src/generation/generate.py defaults correctly.
   - Execute the notebook and verify that a progress bar successfully renders showing question progress.
   - Check the output JSON at tests/voiculescu_et_al/results.json to confirm it holds a valid array of objects exactly
     featuring the keys question, answer, and type.
